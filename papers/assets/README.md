# Paper asset provenance

Images under this directory are page-level extracts from the public arXiv PDFs. They preserve the paper's values and captions; they are not new plots. Each paper directory contains a `SOURCES.md` ledger with the exact source URL, page, figure/table number and reading note.

TinySeek figures are intentionally not copied here. Link them from their canonical locations under `experiments/` so that a result has one source of truth.
